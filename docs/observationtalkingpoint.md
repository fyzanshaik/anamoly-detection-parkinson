# Chart Talking Points — Distributed Edge AI Anomaly Detection

Charts generated by `ML-MODEL/src/visualize_deployed.py` and saved to `ML-MODEL/outputs/deployed/`.

---

## 01 — Score Distribution (`01_score_distribution.png`)

- Autoencoder trained only on normal data — learns what "normal" looks like
- Fault samples produce higher reconstruction error because the model has never seen them
- Threshold set at 95th percentile of normal training data — statistically grounded, not manually tuned
- Clear separation between green (normal) and fault clusters
- Small green tail past threshold = the honest 5.2% false positive rate

---

## 02 — Cycle Trace (`02_cycle_trace.png`)

- Shows one complete 50s operating cycle as it runs on the ESP32
- Score stays flat and low during Normal phase — system is stable
- Rises during Ramp as fault pattern intensifies — early detection
- Clearly elevated during Anomaly — red detected region
- Drops back below threshold during Resolve — system self-recovers without intervention

---

## 03 — Feature Importance (`03_feature_importance.png`)

- 10 features extracted from accelerometer window: 3 axis means, 3 axis stds, 4 magnitude features
- Magnitude features (mag_std, mag_max, mag_mean, mag_rms) dominate — physically correct, real faults manifest as vibration amplitude changes
- Axis means contribute almost nothing — faults don't shift the motor's position, they change its vibration character
- This validates the feature engineering is physically meaningful, not arbitrary

---

## 04 — Training Curves (`04_training_curves.png`)

- Pure numpy implementation — no TensorFlow, no PyTorch — runs on Python 3.14
- Autoencoder converges smoothly in 500 epochs
- Classifier shows two-stage learning: coarse class boundaries first, then fine-tuning
- No oscillation or instability — deterministic training with fixed seeds

---

## 05 — Confusion Matrix (`05_confusion_matrix.png`)

- 97.9% overall accuracy across 4 classes
- Normal: 400/400 — perfect, system never raises false alarm at classifier level
- No fault misclassified as Normal — nothing is missed
- Only confusion: Imbalance ↔ Bearing (15-17 samples) — physically expected since both raise vibration magnitude, just differently
- Looseness: 399/400 — near perfect

## 06 — Model Size (`06_model_size.png`)

- Total: 1196 bytes — fits in 1KB
- ESP32 has 520KB RAM — model uses less than 0.25% of available memory
- Inference runs in microseconds on 240MHz CPU
- No external libraries, no cloud, no network dependency — fully self-contained edge AI
- Two complete neural networks in less space than a single JPEG thumbnail

---

## 07 — Detection Rate (`07_detection_performance.png`)

- 100% detection rate across all three fault types
- True negative rate 94.8% — correctly identifies normal operation 19 out of 20 times
- FPR of 5.2% is a deliberate design choice — threshold tunable, we prioritized catching all faults over minimizing false alarms
- In predictive maintenance, missing a real fault (false negative) is far more costly than an unnecessary inspection (false positive)
